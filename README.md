## 📁 Folder Structure

```
/
├── index.html        ← Main website
├── 404.html          ← Custom error page
├── CNAME             ← Custom domain config (dufladiligon.com)
├── images/           ← ADD PHOTOS HERE (DSC*.JPG files)
│   └── dufla-portrait.jpg
└── README.md
```

## 🖼️ Adding Photos

1. Create an `images/` folder in this repo
2. Copy the DSC*.JPG photos into it
3. Update the gallery section in `index.html` with `<img src="images/DSC08994.JPG" ...>`
4. For the About portrait, add `images/dufla-portrait.jpg`

## 🚀 Deployment (GitHub Pages)

1. Push this repo to `git@github.com:KimJon/dufla.git`
2. Go to **Settings → Pages**
3. Set source branch to `main`
4. Set custom domain to `dufladiligon.com`
5. Tick **Enforce HTTPS**
